# Локална околина

Bi-Dash користи Docker стек со апликација, PostgreSQL за метаподатоци, Redis, работници и Ollama. Не се потребни локални Python или Node.js за користење на контејнерската инсталација.

## Отворање на апликацијата

По свежата инсталација отворете `http://localhost:5001/setup`. По создавање на администраторот користете `http://localhost:5001`.

## Локален и серверски стек

- Локално: `compose.local.yaml` и `.env`.
- Linux сервер: `compose.linux.yaml` и `.env.linux`.

Не мешајте ги командите и конфигурациите меѓу двата стека.

## Проверка на локалните сервиси

```bash
docker compose -f compose.local.yaml ps
docker compose -f compose.local.yaml logs --tail=100 server
```

За повторно стартување користете `docker compose -f compose.local.yaml up -d`. Иницијализирањето на база е само за свежа инсталација.

## Локален AI

Моделот за Ollama се презема посебно. Планирајте доволно RAM и простор за избраниот модел и за изградбата на апликацијата. Надворешен AI провајдер е алтернатива со сопствени трошоци и обработка на податоци.

## Зачувајте ја конфигурацијата

Не споделувајте `.env` датотеки и API клучеви. Правете резервна копија на PostgreSQL и на оригиналните тајни. Не бришете волумени ако сакате да ги задржите извештаите и поставките.
