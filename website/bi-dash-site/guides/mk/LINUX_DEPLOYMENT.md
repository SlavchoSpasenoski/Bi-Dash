# Linux сервер: инсталација и операции

Серверската постапка е наменета за Linux x86-64 со Docker Engine, Buildx, Compose v2, Bash, Git и OpenSSL. Ubuntu 24.04 LTS е соодветна почетна околина. ARM64 и GPU инференција не се валидирани.

Планирајте почетно 4 vCPU, 8 GB RAM и 60 GB диск без локален AI, па измерете ја реалната употреба. За локален AI планирајте најмалку 16 GB RAM на хостот и проверете ја одзивноста.

## Инсталација

Инсталирајте Docker според упатството за вашата дистрибуција. Вашата сметка мора да има соодветен пристап до Docker. Потоа:

```bash
{{linux}}
```

Скриптата создава три независни тајни во `.env.linux` со ограничени дозволи. Апликацијата се гради во Docker. Повторен повик на `install` ги зачувува податоците и тајните и иницијализира само празна база; не мигрира постоечка шема. Не извршувајте повеќе инсталации истовремено.

## Приватен пристап

На вашиот компјутер отворете SSH тунел, заменувајќи ги корисникот и серверот:

```bash
ssh -N -L 5001:127.0.0.1:5001 your-user@your-server
```

Отворете `http://localhost:5001/setup` за првиот администратор, а потоа `http://localhost:5001`. Чувајте го тунелот отворен додека работите. Апликацијата слуша само на loopback; портите на PostgreSQL, Redis и Ollama не се објавени.

## AI по избор

```bash
bash scripts/linux.sh ai
```

Ова го стартува Ollama и го презема `qwen2.5-coder:7b` во траен волумен. По `stop`, употребете `ai` повторно за да го стартувате Ollama. Нема конфигурирано GPU проследување. Можете да изберете надворешен провајдер во **Settings → AI Configuration**.

## Секојдневни операции

```bash
bash scripts/linux.sh status
bash scripts/linux.sh logs
bash scripts/linux.sh stop
bash scripts/linux.sh start
bash scripts/linux.sh check
```

`stop` ги зачувува волумените. Не користете `down -v` освен ако намерно ги бришете податоците.

## Резервни копии и надградба

Чувајте резервна копија на PostgreSQL **и** `.env.linux`. Оригиналниот клуч е потребен за зачуваните пристапни податоци. Не менувајте `POSTGRES_PASSWORD` на постоечки волумен без соодветна промена на лозинката на улогата во базата.

Пред надградба направете резервна копија и следете ја [деталната постапка за надградба и враќање (EN)](/en/downloads/LINUX_DEPLOYMENT.html). Не мешајте ги `.env.linux` и `compose.linux.yaml` со локалниот стек.
