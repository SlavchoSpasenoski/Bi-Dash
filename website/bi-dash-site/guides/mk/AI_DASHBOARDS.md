# AI асистент и контролни табли

AI е опционален. SQL прашањата и контролните табли можете да ги користите без AI провајдер.

## Изберете провајдер

Администратор отвора **Settings → AI Configuration**. Достапни се локален Ollama, OpenAI, Anthropic или OpenAI-компатибилен сервис. Внесете модел што е достапен кај избраниот провајдер и, кога е потребно, сопствен API клуч. За компатибилен сервис внесете ја соодветната основна API адреса.

За локален Ollama не е потребен платен API клуч. Во локалниот Docker стек преземете модел:

```bash
docker compose -f compose.local.yaml exec ollama ollama pull qwen2.5-coder:7b
```

За серверската Linux постапка користете `bash scripts/linux.sh ai`.

## Додајте контекст

Во **Settings → AI Context** зачувајте опис на шемите, деловни дефиниции и правила за метрики. Наведете, на пример, дали приходите се со или без данок и кој датум го дефинира периодот.

## Подгответе SQL

Отворете **AI Assistant**, опишете ја анализата и побарајте SQL. Проверете ги имињата на табелите, филтрите и значењето на резултатите. Разговорот подготвува SQL за рачна употреба.

## Создајте нацрт на контролна табла

Изберете **AI Assistant → Build dashboard**, наведете извор и опишете што сакате да следите. Функцијата создава зачуван нацрт со прашања, визуелизации и почетни резултати. Ограниченото извршување прашања само за читање е достапно за PostgreSQL и MySQL/MariaDB.

Пример за опис: „Креирај месечен преглед на приходите и бројот на нарачки за последните шест месеци.“ Овој пример претпоставува дека соодветните деловни податоци постојат во поврзаниот извор.

Прегледајте и уредете го нацртот пред објавување. AI резултатите може да содржат грешки.

## Податоци и трошоци

Локалниот модел работи во вашата околина. При избор на надворешен провајдер, AI барањата се обработуваат кај него и може да се наплатуваат. Не внесувајте лозинки и тајни во описите.
