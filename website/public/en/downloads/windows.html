BI-DASH / WINDOWS

Get started on Windows.

Bi-Dash is downloaded as source code and installed with Docker. All systems use the same ZIP archive, with different installation steps.

Prerequisites: Docker Desktop with Linux containers, Git and PowerShell 7.

Download Bi-Dash ZIP ↓

Extract the archive and open a terminal in the Bi-Dash-main folder. Continue with the steps after downloading, or use git clone as shown in the guide.

Open the complete guide → · Save the guide ↓

Initialize a fresh database only once. For an existing installation, follow the restart or upgrade steps.

Windows with Linux containers has been verified. A complete fresh installation on physical Linux/macOS hosts and ARM compatibility still require validation.
