BI-DASH / LINUX

Започнете на Linux.

Bi-Dash се презема како изворен код и се инсталира преку Docker. ZIP-архивата е иста за сите системи; постапката за инсталација е различна.

Предуслови: Docker Engine, Compose v2, Git, Bash и OpenSSL. Серверската постапка е за x86-64.

Преземи Bi-Dash ZIP ↓

Отпакувајте ја архивата и отворете терминал во папката Bi-Dash-main. Потоа следете го упатството од чекорот по преземањето, или користете git clone според упатството.

Отвори целосно упатство → · Зачувај упатство ↓

За свежа база употребете ја иницијализацијата само еднаш. На постоечка инсталација следете ги чекорите за стартување или надградба.

Windows со Linux контејнери е проверен. Целосна свежа инсталација на физички Linux/macOS хост и ARM компатибилноста сè уште бараат валидација.
