# Bi-Dash brand kit

Original Bi-Dash contributions © 2026 Slavcho Spasenoski, to the extent protected by applicable copyright law. Distributed under the repository's BSD 2-Clause license; see ../LICENSE and ../NOTICE.

- `bi-dash-mark.svg`: primary editable vector mark.
- `bi-dash-mark-dark.svg`: light-blue mark for dark backgrounds.
- `bi-dash-mark-monochrome.svg`: inherits the surrounding text color.
- `bi-dash-wordmark.svg` and `bi-dash-wordmark-dark.svg`: horizontal lockups.
- `icon-*.png` and `favicon.ico`: raster exports.
- `preview.html` and `preview.png`: light/dark visual reference.

See ../BRANDING.md for sizing, colors and attribution. The wordmark uses the installation's Segoe UI/Arial sans-serif font stack; no font files are distributed.
